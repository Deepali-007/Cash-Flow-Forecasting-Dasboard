
# Cash Flow Forecasting & Dashboard

## Project Overview
This project focuses on cash flow forecasting and monitoring monthly cash positions using Microsoft Excel and Power BI.

## Tools Used
- Microsoft Excel
- Microsoft Power BI

## Key Analysis
- Forecast cash inflows and outflows
- Monthly forecast net cash flow
- Forecast closing cash balance
- Monthly cash surplus or shortfall
- Cash flow trend analysis

## Project Files
- Excel workbook: Cash flow data, forecasting calculations and analysis.
- Power BI report: Interactive cash flow forecasting dashboard.
- Dashboard screenshot: Visual preview of the completed dashboard.

## Project Objective
To understand projected cash movements, monitor cash surpluses or shortfalls, and support financial planning through data visualization.

## Disclaimer
This is an independent portfolio project using sample financial data for educational and analytical purposes.
